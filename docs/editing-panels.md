# Editing panels

Photo Studio groups the existing tools into Color & light, Portrait studio,
Masks, Reference matching, Automatic finish, and History. All tools shows them
together. Precision retouch opens the separate brush and saved-operation
workspace.

The photograph stays beside the controls on wider windows. On narrow windows,
the controls stack below it. Switching panels keeps reference names, strength
drafts, and saved settings. It stops any active neutral picker, mask drawing,
or liquify brush so that a hidden tool cannot change the photograph.

Automatic finish is available directly from Photo Studio after automatic
retouch. Open Adjust automatic finish to change overall or category strengths,
then apply once. These are the same saved-operation controls used in Precision
retouch. Undo and Redo remain available while working in any panel; History
contains snapshots and the complete saved-edit timeline.

Panel navigation does not introduce new image-processing algorithms or certify
equivalence with another editor. It organizes AURA's existing native tools.

Reference matching also includes independent regional colour strengths. See the
[reference workflow](adjustable-finishing-and-reference-colour.md#match-regions-independently)
for analysis, supported regions and limits.
