## Defects found while completing the gate

**The append-only trigger and the `supersedes` foreign key were mutually exclusive.**
Compaction deleted a superseded row, SQLite's `ON DELETE SET NULL` tried to null the pointer
on the row that superseded it, and `decisions_no_update` aborted the transaction. The whole
compaction failed with `AURA-DB-3006` and a message about the ledger being append-only -
which was correct and completely unhelpful. Caught by the compaction test in
`explain_eval.rs`, fixed by dropping the foreign key and documenting why a dangling backward
pointer is the right answer. Migration 13 carries the argument.

**Composition's four "nothing was measured" codes are inside `is_exoneration`.** The first
version of the registry tested exoneration before caveat, so `keypoints_unavailable` and
`aesthetic_unavailable` were being read as notes - which would have rendered "AURA did not
look at this" in the same voice as "this is fine". Caught by
`a_code_that_admits_an_absence_is_a_caveat_and_never_a_fault`, which is now the test that
pins the ordering for all four vocabularies at once.

**The grounding check was too strict about rounding.** An early version compared numeric
tokens verbatim, so a summary saying "0.4" against a fact carrying "0.40" was reported as
fabricated. A check that cries wolf is a check somebody turns off, so the comparison
normalises trailing zeroes - and the test that catches an invented shutter speed still passes.
